# Independent Forecast Reporting Authority

## Decision and Plan

Primary evaluation uses 300 targets; supplementary sensitivity uses 500.
The former 1,000-target reporting is `DEPRECATED_FOR_REPORTING`, not deleted
from scientific history. This retrospective scope change is disclosed in both
manuscripts. It is not new model tuning, an untouched-test confirmation, or
evidence that MAE dispersion has been resolved. Historical criterion-specific
forecast-guided selection remains disclosed.

The implementation stages are: freeze a no-inference reporting policy; replay
the approved draw-wise prefixes; audit companion coverage; project an IND-only
article packet; test/freeze dedicated branches for coordinator integration.
This refines the ignored detailed plan under the recovery worktree's
`local_trackers/prefix_scope_revision_20261015/` with the verified VB omission.

Training remains 8501:9000. Primary targets 9001:9300 contain ten origins;
sensitivity targets 9001:9500 contain 17 origins, last lead 20. Stride and
maximum lead remain 30. Targets, not origins, receive equal weight.
Specifications, priors, seeds, inference transitions and runtime snapshots
are frozen. No refitting, forecast simulation, package substitution, winner
reselection or favorable-realization retry is permitted.
