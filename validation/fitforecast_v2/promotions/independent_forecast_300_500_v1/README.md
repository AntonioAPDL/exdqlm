# Independent Forecast Reporting Packet

300 targets are primary and 500 supplementary sensitivity. The former
1,000-target evaluation is deprecated for reporting, with historical evidence
retained. This is a retrospective scope revision, not a model improvement.

The packet contains 144 forecast cells from 44 frozen three-chain sources,
72 unchanged MCMC/VB fit cells, DGP references, replay checks, policy,
authority transition, comparisons, source locators and hashes. VB prefix
forecasts are explicitly omitted because authentic granular paths are absent;
aggregate full-period draws cannot identify prefix intervals. No new fits or
forecasts are authorized. Preserve protected fitted/joint-path binaries in
their ignored locations; do not copy them into Git.

The dedicated Article-v2 preparation branch carries the publication assets,
IND-only renderer/checker, revised projection allowlist and manuscript proofs.
Integration and Overleaf publication remain coordinator actions. See
`validation/fitforecast_v2/docs/independent_forecast_reporting_300_500_v1.md`.
